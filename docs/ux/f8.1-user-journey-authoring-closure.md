## F8.5 Persistence & Feedback Closure

- Course metadata is normalized from CRLF/CR to LF immediately before server-side validation and persistence. The normalizer preserves authored whitespace and only makes the 4,000-character boundary platform-independent. Forge targets a 3,800-character course proposal as a final safety margin.
- Course Save emits length-only operational telemetry (`formDataChars`, `normalizedChars`, validation result) and revalidates the course and library routes. Apply remains local; the editor now says whether a change is applied to the draft or saved.
- Public Preview now emits minimal telemetry (field lengths, format, output budget, finish reason, elapsed time, result code), while intentionally excluding prompt, intent, output and private data. The pipeline retains its structured-output and non-`stop` rejection contract.
- Forge pending feedback now names the active operation and exposes polite live status. Answer dialogs offer regenerate and a follow-up precision request; only proposals expose Apply.
- Owner preview is offered whenever an owner has a lesson to preview, independent of enrollment; the existing access contract keeps it read-only and prevents progress writes.
- Workspace-home composer and broader owner-cockpit work remain F9 scope. Browser verification remains required for public generation, persistence and responsive checks.

## F8.2 closure

Create keeps F8.1's real-domain guard: a suggested label that has no matching persisted domain is now a prompt to choose a real domain, and the create CTA remains disabled. The proposal remains rendered after a server error; the session draft is only consumed after successful creation. Real persistence remains blocked in this environment: the local browser has no valid Supabase refresh token (`refresh_token_not_found`), so no owner session or external write can be verified.

The former course-level free-prompt `invalid_request` was a contract issue: `ask` was excluded when no lesson slug was present. It is now valid at course scope. Forge quick actions and free prompts use the same `run` function. Edit proposals have a compact rail preview and an accessible native modal dialog for full reading. The dialog supplies native modal focus containment, Escape and focus return; it has a semantic title, close control, internal scroll, responsive dimensions and sticky decision footer. Regenerate resubmits the remembered request and selected sources; adjustment resubmits that request with the current proposal and additional instruction. Neither action writes course content. Apply still transfers only to the lesson draft, which requires explicit Save.

The workspace now uses a 300px Structure column and 380px Forge column on desktop, while editor children retain a 760px reading measure. Below 1099px the existing Structure/Forge modal panels take over. Browser checks at the requested viewport sizes remain blocked by the missing authenticated session. The local unauthenticated home renders, but the server reports the invalid stored refresh token; this is an environment session issue, not a React #441 reproduction.

## F8.3 closure

### Auth recovery

A shared authenticated local browser session reached `/app` and showed the owner navigation. A browser reload initially retained that protected session, confirming that the prior `refresh_token_not_found` was an obsolete local browser session rather than an application credential or callback defect. The UI automation browser subsequently failed at its own navigation layer with `ERR_NETWORK_IO_SUSPENDED`; the Next server remained listening on port 3000. Further browser checks are therefore blocked by the automation environment, not treated as application proof.

### Real create evidence and fixes

With the shared owner session, the public intent flow produced a preview for **Parcours : Fondamentaux du Design System (Débutant)**. The user selected the persisted `Creation web` domain and submitted creation. The action persisted a course owned by the session user with 6 modules and 18 lessons; the course appeared in **Mes parcours** and its structure was visible in the editor.

The initial redirect reached a 404 lesson URL. The F8.1 edit-entry redirect had selected the first lesson route automatically. It is removed: edit now opens the known working course editor root and leaves lesson selection explicit.

The library initially displayed `Sans domaine` for the newly persisted `Creation web` domain. The actual Supabase many-to-one `domains(name)` result is an object, while the repository typed and read it as an array. `domainNameFromRelation` now supports the real object projection and the prior array shape, with unit coverage. No domain data was changed.

### Remaining browser QA blocker

The post-fix full refresh, provider calls, source witness, proposal interaction, responsive viewports, dark mode, keyboard dialog checks, console review and logout were not completed because browser navigation was suspended by the automation host. They must be re-run in a functioning shared browser session before F8.1/F8.2 closure.
