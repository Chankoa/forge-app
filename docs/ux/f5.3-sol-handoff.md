# F5.3 Sol Handoff

## Preserved Starting Point

This handoff records the actual work present when Terra resumed F5.3. No reset, revert, branch switch, or replacement implementation was performed.

- `AppShell` introduces the split between the Workspace shell and the Course shell.
- `CoursePresentation` provides the shared Course cover placeholder, relationship pills, progress ring, metadata, and canonical card composition.
- `presentation.ts` owns truthful relationship ordering, progress clamping, and cover-availability detection.
- `WorkspacePanels` continues to own desktop rail states and compact drawers; `CourseOutlineRail` reuses it for the Structure timeline and `ForgeRail` reuses it for the Forge rail.
- `ThemeToggle` now renders exactly one state-appropriate icon and accessible label.
- Course Overview, My Courses, Explorer, Create, Learn, Edit, and Publication received their F5.3 presentation wiring.

## Backend Cover Audit

The current contracts and repositories do not expose a course cover URL, image URL, thumbnail, or equivalent field. The historical `course-covers` storage reference is not a demonstrated application contract. F5.3 therefore uses the deterministic `CourseCover` placeholder and does not introduce storage, URLs, migrations, or invented metadata.
